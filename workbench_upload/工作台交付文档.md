## 四、feishu.py 架构

```
FeishuClient（模块级单例）
├── token 管理
│   ├── 启动时拉取 tenant_access_token（app_id + app_secret）
│   ├── 后台线程每 90 分钟自动刷新
│   └── get_token() 临期自动重刷
│
├── webhook 中转
│   ├── _webhook_sign()     HMAC-SHA256 签名
│   ├── _post_webhook()     单次 POST（去 timestamp/sign + 重新签名）
│   └── broadcast_webhook() 遍历所有已配置 webhook（同 URL 去重）
│
├── bitable 中转
│   ├── _parse_field_for_bitable()  文本→飞书类型转换
│   │   ├── 日期 "2026-07-31" → 毫秒时间戳（短日期）
│   │   ├── 本期值/上期值/环比 "%" → 小数（百分比字段）
│   │   └── 是否异常 "是/否" → true/false（复选框）
│   ├── bitable_batch_create()     批量写入（自动加 Bearer token）
│   └── bitable_status()           配置状态
│
└── DM 推送（可选）
    └── send_dm()  App 身份发私信（需 my_open_id）
```

## 七、出单监控 wrapper 工作原理

`出单监控_workbench.py` 解决原脚本依赖 tkinter 的问题：

```
CLI 参数 (--today --yesterday --password --date)
    ↓
monkey-patch tkinter（在 import 原脚本前注入）
    ├── askstring → 返回 CLI 参数
    ├── askopenfilename → 返回 CLI 文件路径
    ├── showinfo/showerror → 静默
    └── Tk → FakeTk（不创建窗口）
    ↓
import + exec 原脚本
    ↓
显式调用 mod.main()（因为 exec_module 不会自动触发 if __name__ == "__main__"）
    ↓
input("按回车键关闭...") 保持窗口可见
```

**启动方式：** `subprocess.Popen(..., creationflags=CREATE_NEW_CONSOLE)` — 弹出独立 CMD 窗口。

## 十、日常使用流程

1. 双击桌面 `支付运营工作台.vbs`（自动启动工作台 + 打开浏览器）
2. 确认首页 5 项全绿
3. 每日转化率：点"一键配置并打开" → 上传 Excel → 自动同步飞书
4. 出单监控：选两个 Excel + 填日期 + 填密码 → 点击启动 → 看弹窗输出
5. （有异常时）点商户成功率做深挖
6. 关掉桌面快捷方式的进程（或不管，占用很小）
